# Ads Helper — генератор рекламных постов

Streamlit + **Google Gemini**. Вход по **email**, лимиты в **SQLite**, подписка активируется **вручную** через админ-панель после оплаты на карту.

## Тарифы

| Тариф | Лимит |
|-------|--------|
| **Бесплатный** | 3 генерации на аккаунт (навсегда) |
| **Подписка 990 ₽ / 30 дней** | 100 000 токенов в месяц (~сотни постов; рассчитано на ~10 платных пользователей на одном ключе Gemini) |

Дополнительно: пауза **3 сек** между запросами (защита от спама кнопки).

## Быстрый старт

```bash
pip install -r requirements.txt
copy .env.example .env
# Заполните GEMINI_API_KEY, ADMIN_PASSWORD, CONTACT_TELEGRAM
streamlit run app.py
```

## Secrets (Streamlit Cloud)

```toml
GEMINI_API_KEY = "..."
ADMIN_PASSWORD = "ваш_секретный_пароль"
CONTACT_TELEGRAM = "@ваш_ник"
DATABASE_PATH = "data/ads_helper.db"
```

> **Важно:** на Streamlit Cloud файл SQLite может сбрасываться при передеплое. Для продакшена позже подключите Supabase/Turso; для старта и тестов SQLite подходит.

## Работа с оплатой (ваш процесс)

1. Клиент **регистрируется** по email на сайте.
2. Пользуется **3 бесплатными** генерациями.
3. Переводит **990 ₽** на карту, пишет вам в Telegram **свой email** с сайта.
4. Вы в сайдбаре: **«Вход для администратора»** → пароль → **«Активировать подписку»** → email клиента.
5. Клиент обновляет страницу — видит подписку и лимит токенов.

## Переменные

| Переменная | Описание |
|------------|----------|
| `GEMINI_API_KEY` | Ключ Gemini |
| `ADMIN_PASSWORD` | Пароль админ-панели в сайдбаре |
| `CONTACT_TELEGRAM` | Контакт в баннере подписки |
| `DATABASE_PATH` | Путь к SQLite (по умолчанию `data/ads_helper.db`) |
