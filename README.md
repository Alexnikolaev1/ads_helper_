# Ads Helper — генератор рекламных постов

Streamlit-приложение на базе **Google Gemini**: по брифу и настройкам (платформа, тон, длина) создаёт несколько готовых вариантов постов с CTA и хештегами.

## Структура проекта

```
ads_helper/
├── app.py                 # Точка входа (streamlit run app.py)
├── ui/
│   ├── main.py            # Главный экран
│   ├── components.py      # Карточки, hero, история
│   └── styles.py          # CSS
├── src/
│   ├── config.py          # Настройки, платформы, API-ключ
│   ├── prompts.py         # Промпты под платформу/тон
│   ├── services/gemini.py # Вызов Gemini с fallback моделей
│   └── utils/parser.py    # Разбор ответа на варианты
├── .streamlit/config.toml
└── requirements.txt
```

## Быстрый старт (локально)

### 1. Установите зависимости

```bash
cd ads_helper
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Получите API-ключ Gemini

1. Откройте [Google AI Studio](https://aistudio.google.com/apikey)
2. Создайте ключ API

### 3. Настройте секреты (один из способов)

**Вариант A — `.env` в корне проекта:**

```bash
copy .env.example .env
```

Отредактируйте `.env`:

```
GEMINI_API_KEY=ваш_ключ
```

**Вариант B — Streamlit secrets:**

```bash
mkdir .streamlit
copy secrets.toml.example .streamlit\secrets.toml
```

Вставьте ключ в `.streamlit/secrets.toml`.

### 4. Запустите приложение

```bash
streamlit run app.py
```

Откройте в браузере адрес из терминала (обычно `http://localhost:8501`).

## Деплой на Streamlit Cloud (бесплатно)

1. Залейте репозиторий на GitHub (без `.env` и без `secrets.toml`!)
2. [share.streamlit.io](https://share.streamlit.io) → **New app**
3. Repository + ветка + `app.py`
4. **Settings → Secrets** → вставьте:

```toml
GEMINI_API_KEY = "ваш_ключ"
```

5. Deploy — получите публичную ссылку для клиентов.

## Функции

| Функция | Описание |
|--------|----------|
| Платформы | VK, Telegram, Instagram, Avito, универсальный |
| Тон и длина | 6 тонов, 3 длины текста |
| 2–5 вариантов | Настраиваемое количество |
| Эмодзи / хештеги / CTA | Переключатели в сайдбаре |
| Счётчик символов | С предупреждением при превышении лимита |
| Скачивание | Все варианты или по одному (.txt) |
| История | Последние 10 генераций в сессии |
| Перегенерация | Обновить один вариант без полного цикла |
